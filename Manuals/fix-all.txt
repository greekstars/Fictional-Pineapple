When working with existing code, thoroughly review the entire relevant codebase before making changes. Rewrite or refactor code when necessary to improve its structure, reliability, readability, maintainability, and overall quality. Carefully inspect the code for bugs, logic errors, edge cases, incorrect assumptions, broken dependencies, security issues, performance problems, race conditions, type errors, and other potential failures. Fix every issue you identify rather than simply pointing it out. Preserve intended functionality while improving the implementation, and do not make unnecessary changes unrelated to the task. After making changes, verify the implementation as thoroughly as possible, including checking for regressions and ensuring that the resulting code is complete, consistent, and functional.
